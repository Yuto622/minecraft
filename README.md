# BLOCKWILD — ブロックの世界

森と山と湖でできた島をひとつ生成し、掘って、灯をともして、積み上げていく
3D サンドボックス。ブラウザだけで動きます。依存は three.js（同梱）のみ、
ビルド工程はありません。`dist/` をそのまま静的配信すれば遊べます。

```
dist/index.html   ← これを開くだけ
```

スマホは左下のスティックで移動、画面右側のドラッグで視点、右下のボタンで
壊す・置く・持ち物。

PC でもマウス操作が合わないときは、**設定 →「画面に操作ボタンを表示する」**で
スティックとボタンを出せます（このときマウスは固定されず、ドラッグで視点）。
マウス固定（ポインタロック）が使えない環境では自動でこの表示に切り替わります。

段差は 1 ブロックまで自動で上るので、歩いているだけで坂や階段を登れます。
Esc はまずマウス固定を外し、もう一度押すとメニューが開きます。画面右上の
Ⅱ ボタンからもいつでもメニューに戻れます。

### 本家に寄せたところ

- 壊したブロックは**その場に落ちて**、近づくと吸い寄せられて拾えます。
- 持ち物は **36 マス・1 山 64 個**。左クリックで丸ごと掴む、右クリックで半分／1 個ずつ、
  Shift+クリックでまとめて移動、数字キーで指しているマスをホットバーへ。
- クラフトは**格子に材料を並べる方式**。持ち物では 2×2、作業台のそばでは 3×3 に広がります。
  レシピ帳をクリックすると材料を自動で並べます。
- **かまど**は燃料と時間で精錬します（砂→ガラス、原石→インゴット、粘土→レンガ、生肉→焼き肉）。
  **チェスト**は 27 マス。壊すと中身が飛び散ります。
- **階段・ハーフブロック・柵・板ガラス・ドア・ベッド**は立方体ではない形を持ち、
  向きも記録されます。柵と板ガラスは隣とつながり、ドアは右クリックで開閉します。
  ベッドは夜に寝ると朝になります。
- **砂と砂利は支えを失うと落ち**、幹を切られた**葉はしばらくすると枯れて**落ちます。
- 破壊中はブロックに**ひびが10段階**で入ります。
- 夜には**ゾンビとクリーパー**。クリーパーは近づくと膨らんで爆発し、地形に穴を開けます。
- **雨と雪**が降ります。雪原では雪、それ以外では雨。空が暗くなり、音も変わります。
- 体力と満腹度は**ハートと肉のアイコン**で表示します。

**クリエイティブ**は全ブロックが無限、飛行あり。
**サバイバル**は手ぶらで開始し、木 → 木材 → 棒 → 道具の順に育てていきます。
石は木のツルハシ以上、鉄鉱石は石のツルハシ以上でないと採れません。
夜は暗いところにゾンビが湧くので、松明かランタンを持って潜ること。

### 光のこと

この世界の明るさは「空の光」と「光源の光」を 4bit ずつ 1 バイトに詰めて
ボクセルごとに保持しています（`world.js`）。生成時に一度だけ全体を BFS で
伝播させ、以降はブロックを置くたびに周囲 16 ブロックだけを再計算します。
そのため洞窟は本当に暗く、松明を 1 本置けばその場所から光が広がり、
明るさが変わったチャンクだけが静かに作り直されます。

昼夜は頂点に焼いた明るさをシェーダのユニフォームで混ぜて表現しているので、
時間が進んでもメッシュの作り直しは起きません。

### メッシュのこと

チャンクは 16×64×16。見えない面を落とし、頂点ごとにアンビエント
オクルージョンと周囲 4 セルの平均光量を計算して焼き込みます。テクスチャは
`DataArrayTexture`（WebGL2 の配列テクスチャ）なので、タイル同士の
にじみがなくミップマップが安全に効きます。

## 開発用フック

ブラウザのコンソールから `window.BLOCKWILD` で中身を触れます。

```js
BLOCKWILD.setTime(720 * 0.9)          // 夜にする
BLOCKWILD.give(37, 16)                // たいまつを16本
BLOCKWILD.changeBlock(100, 40, 100, 31) // グロウストーンを置く
BLOCKWILD.state                        // モード・所持品・時刻など
```
